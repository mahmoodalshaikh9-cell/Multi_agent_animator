
title: Automated animation engine

deployed app link : https://multiagentanimator-dmivffbfwfdaacybs66sat.streamlit.app/

problem: Genrative AI users often often need to plan, prompt, review, and make edits especially with visual outputs such as animation. this process is time consuming and requires human intervention on each stage.

solution: This project is a Multi agent pipeline that manages the whole process after the user initial prompt, extracting requirements, refining prompts, evaluating outputs and fixing errors.
